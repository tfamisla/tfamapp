🔗 Google Sheets Setup Guide
Step 1
Create a new Google Sheet. Name the first row with these headers in order:

ClaimNumber | InspectionDate | Latitude | Longitude | GPSAccuracy | InspectionAddress | District | PINCode | FloodLevel | FloodLevelUnit | DamageDetails | EstimatedLoss | NetAssessedLoss | Remarks | NumPhotos | SignatureObtained | Status | SyncStatus | LastUpdated
Step 2
In Google Sheets, go to Extensions → Apps Script. Delete existing code and paste the Apps Script code (copy it from the button below).
Step 3
Click Deploy → New Deployment. Choose type Web App. Set Execute as: Me, Who has access: Anyone. Click Deploy and copy the URL.
Step 4
Paste the URL into the Apps Script URL field in Settings.
